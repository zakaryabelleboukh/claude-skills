## 📦 Installation

Each skill is self-contained. Open the relevant folder and use its `SKILL.md` with Claude's Skills interface.

For skills that depend on external connectors, such as Figma Expert, Claude must have access to the relevant connector/tools.

## 🧭 Design philosophy

These skills are designed to make Claude operate as a specialized expert rather than a generic chatbot. They emphasize structured workflows, reusable systems, verification, quality control, explicit assumptions, and honest handling of uncertainty.
