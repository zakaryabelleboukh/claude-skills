## Philosophy

These skills are designed to make Claude operate as a specialized expert rather than a generic chatbot. Each skill emphasizes structured workflows, reusable systems, verification, quality control, and honest handling of uncertainty.

## Installation

Each skill is self-contained. Open the relevant skill folder and upload its `SKILL.md` according to the Claude Skills interface.
