# 🎨 Figma Expert

A production-oriented Claude Skill for senior Figma, UI/UX, design systems,
Auto Layout, variables, responsive design, accessibility, visual QA, and
Figma-to-code workflows.

## Best use

Give Claude a Figma link and an objective. Ask it to inspect first, reuse your
existing design system, make the requested changes, then verify the result.

Example:

```text
Act as my Senior Product Designer and Figma Expert.
Inspect this Figma screen first. Reuse my existing components and variables.
Improve hierarchy, spacing, typography and usability. Use Auto Layout.
Do not create duplicate components. Perform visual QA after editing.
```

> Requires appropriate Figma access/tools in Claude. Not an official Figma or Anthropic product.
