# 📣 Facebook Community Content Engine

A community-first Claude Skill for producing Facebook posts across gaming,
humour, memes, discussion, education, tech, entertainment and other community niches.

It can pair each post with a structured image-generation brief so the copy and
visual are designed together.

## Example

```text
Create 7 Facebook posts for a gaming community.
Mix humour, discussion, gaming facts and relatable posts.
For every post provide the final caption plus a production-ready image prompt.
```

> Independent community-created skill. Not an official Meta or Anthropic product.
